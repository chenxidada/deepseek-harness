## 术语（全文统一）

| 术语 | 含义 |
|------|------|
| **Host** | Extension Host 侧控制器与权威状态持有者（`ConversationController` / `ChatPanelHost` 等） |
| **Editor Chat Panel** | 编辑器区 `WebviewPanel` 承载的主对话面（本 feature 目标壳层） |
| **侧栏 View** | 现有 `WebviewView`（`dsh.chat`）及/或 Conversations `TreeView` Tab 条 |
| **面板内顶栏 Tab** | Editor Chat Panel **内部** chrome 上的多会话 Tab（非 VS Code 侧栏 TreeView；非「每会话一个 VS Code editor tab」） |
| **ConversationRegistry** | 扩展侧 Tab 身份权威：`tabId` / `sessionId` / `activeTabId` / 未关集合等 |
| **决策态** | Host 裁决：`mode` / `sessionId` / 能否发送 / Continue / 变更审阅权威结果等 |
| **呈现态** | Webview 可持有：滚动、展开折叠、流式中间态、跟滚、`follow-state` 等 |
| **层 A** | 可脚本 DOM（jsdom 等）按固定 DOM 契约断言真实节点/属性 |
| **层 B** | Host/控制器/协议证据（FakeWebview、索引、cancel/fork 调用结果等） |
| **层 V（Visible）** | **人眼可用**证据：在真实 VS Code 扩展宿主中打开 Editor Chat Panel，核对关键 chrome 与信息层级**可见可读**。Must 达标 = **层 A + 层 B + 层 V** |
| **可用级呈现** | 日常可阅读：settle 后 Markdown 可读、层级分明、活动/引用/变更可见可操作、composer 可用 |
| **搜索档 1 / 2 / 3** | 标题+预览 / 变更路径→session / 正文全文（档 3 **本 feature 不做**） |
| **live / replay** | Host `mode`：live 可发送；replay 只读，禁直接发送（可提供 Continue→live） |
| **composer 四态** | **live** / **readonly** / **waiting** / **error**；层 V 必须可区分 |
| **历史窗口** | Editor Chat Panel **面板内**可浏览的历史会话列表（可由顶栏历史入口打开）；**必须不**仅以命令面板 QuickPick 冒充 |

## 产品目标

将对话主界面升级为编辑器区 `WebviewPanel` + 面板内顶栏多 Tab，补齐日常可用完整 UI（含生命周期、只读、错误/空态、入口发现性、删除、Continue），**全文 Must、无 Should**。

## 问题陈述

| 表面 | 现状 | 本 feature 要解决 |
|------|------|-------------------|
| 主聊天面 | 侧栏窄 WebviewView | 编辑器区宽面主入口 |
| 多会话 Tab | 侧栏 TreeView 与内容分离 | 顶栏 chrome；对齐 Registry |
| 人眼体验 | chat-ux 推迟 UI | 可见可用 Must |
| 能力入口 | 分散/命令为主 | 面板内可发现 |
| 边界 | 关 Panel、外部跳转、只读、删除等 | 全部 Must 化 |
| Should 偷懒 | 低频能力易被跳过 | E14 / AC-45 禁止 Should |

## 目标终态

1. 用户**主动**打开 → Editor Chat Panel；不因未关会话自动弹。
2. 顶栏：标题更新、活动/running/角标、关闭/删除、新建、历史、搜索、溢出；切换不串台；Registry 实时同步。
3. 消息流：Markdown settle+sanitize；空态/loading；活动可展开；引用可插入；变更可审阅/撤销；复制入口可见。
4. Composer：四态 + 停止中；禁用有原因；I-真 cancel；跟滚。
5. fork/重试/Continue/复制/Change/搜索/删除：面板内可发现；replay 只读；Continue=same-id。
6. **历史窗口**：顶栏入口打开面板内可浏览列表（非 QuickPick）；条目含标题/时间/预览或路径；打开去重+只读；Continue/删除/档1+2搜索/父子关系；空态/loading；实时同步。
7. 关 Panel×running：后台继续+提示。
8. 层 A+B+V；无 Should。

## 预期范围

### 在范围内（全部 Must）

- 壳层 WebviewPanel；废弃侧栏主聊天；不自动弹 Panel。
- 生命周期：恢复、外部切会话、waiting/error、关 Panel×running。
- 顶栏：标题、running、角标、关闭 fallback、running 确认、新建、历史、搜索、溢出（删除+Timeline）、Tab 溢出可达、Registry 实时。
- **历史窗口（F5）**：面板内可浏览列表；条目信息；打开规则；只读；Continue；删除；档 1/2 搜索联动；父子关系；空态/loading；实时同步；**禁止**仅 QuickPick。
- 消息流：Markdown sanitize、空态/loading、活动展开、引用插入、变更审阅/撤销、composer 四态+停止中、跟滚、失败提示、可见复制。
- 历史只读 + Continue same-id。
- 删除会话（≠ 关 Tab）：顶栏右键+溢出与历史窗口入口一致（Q-6 / E16 / AC-13c / AC-55 / AC-60）。
- 验收层 A+B+V；无 Should。

### 不在范围内

见「不在范围内」专节。

## 验收标准（EARS 格式）

### F0 — 壳层

**AC-1**（普遍型）：系统 **必须** 将主聊天面承载于编辑器区 `WebviewPanel`；**必须不**将仅侧栏 `WebviewView` 作为主聊天面。

**AC-1b**（事件驱动型）：**当** Panel 首次创建或再次打开时，系统 **必须** 恢复未关 Tab 集与有效 `activeTabId`；无未关会话时 **必须** 展示空态新建引导；**必须不**无提示空白面板。

**AC-1c**（事件驱动型）：**当** 从搜索/历史/变更等外部入口打开会话时，系统 **必须** 创建并聚焦 Panel，并切换到目标会话；**必须不**仅通知不切换。

**AC-1d**（状态驱动型）：**在** Host 未连接/等待/错误期间，Panel **必须** 有可见状态提示，composer **必须** 禁用且原因可感知。

**AC-1e**（事件驱动型）：**当** 关闭 Panel 且存在 running 会话时，系统 **必须** 后台继续并给出可见提示（Q-5=A）；**必须不**因关 Panel 静默 cancel。

**AC-1f**（不期望行为型）：**如果** 扩展启动或工作区激活且存在未关会话，**那么** 系统 **必须不** 自动打开 Panel（Q-7=A）；Panel **必须** 仅因主动打开、外部跳转（AC-1c）或文档标明的显式用户动作出现。

**AC-2**（事件驱动型）：**当** 用户执行打开 Conversation 主入口时，系统 **必须** 打开或聚焦 Panel 并使其在编辑器区可见。

**AC-3**（状态驱动型）：**在** Panel 已绑定 Host 期间，决策态 **必须** 由 Host 下发；Webview **必须不**自行裁定能否发送。

**AC-4**（不期望行为型）：**如果** 用户走已废弃侧栏主聊天路径，**那么** 系统 **必须** 打开/聚焦唯一主面或提示已迁移；**必须不**提供第二套可读写消息流。

**AC-5**（普遍型）：系统 **必须** 只保留一个主聊天界面；TreeView Tab 条 **必须不**再作为多会话主切换面。

### F1 — 面板内顶栏 Tab

**AC-10**（普遍型）：Panel **必须** 在顶栏展示多会话 Tab chrome，投影 Registry 未关集合；**必须不**仅以侧栏 TreeView 冒充。

**AC-10a**（普遍型）：Tab **必须** 展示 running 指示，并保留未读/审批角标（若已有）；**必须不**仅 active/inactive。

**AC-10b**（状态驱动型）：**在** 该会话已有首条用户或助手消息、或已有非空标题期间，Tab 标题 **必须** 更新为可区分文本；**必须不**长期无意义占位（如仅「New」/空串）。

**AC-10c**（事件驱动型）：**当** Registry 新增/关闭/删除/切换活动时，顶栏 **必须** 实时更新；**必须不**要求手动刷新。

**AC-11**（事件驱动型）：**当** 点击非活动 Tab 时，系统 **必须** 切换活动与发送目标；**必须不**串台。

**AC-11a**（事件驱动型）：**当** 返回原 Tab 时，系统 **必须** 恢复该会话呈现态（至少滚动与折叠），或使用文档标明的确定性默认态；**必须不**串态。

**AC-11b**（普遍型）：系统 **必须** 有层 A+B 证据：消息流/活动/变更/composer 全随 `activeTabId`；**必须不**跨 Tab 混合。

**AC-12**（事件驱动型）：**当** 激活新建时，系统 **必须** 创建新 tab/session，设为活动，展示可输入空态。

**AC-13**（事件驱动型）：**当** 关闭顶栏 Tab 时，系统 **必须** 执行前序关 Tab 策略（可恢复；running 确认）并更新顶栏。

**AC-13a**（不期望行为型）：**如果** 关闭活动 Tab，**那么** 系统 **必须** 激活相邻或最近未关 Tab；仍有未关时 **必须不**无活动 Tab；全部关闭时 **必须** 空态引导。

**AC-13b**（事件驱动型）：**当** 关闭 running Tab 时，系统 **必须** 确认；**必须不**静默关闭。

**AC-13c**（事件驱动型）：**当** 用户在顶栏 Tab 的右键菜单或溢出菜单触发「删除会话」时，系统 **必须** 弹出确认并提示不可恢复；确认后执行与历史窗口相同的删除动作，并从顶栏、历史窗口、`ConversationRegistry`、持久化、索引中同步移除（Q-6 / AC-60）；**必须不**静默删除；**必须不**将关 Tab 冒充删除。

**AC-14**（普遍型）：顶栏 **必须** 提供历史入口与溢出菜单；历史入口 **必须** 打开面板内历史窗口（F5 / AC-50），**必须不**仅跳转 QuickPick；历史/搜索以面板 UI 为主（Q-3=A）。

**AC-14a**（事件驱动型）：**当** 从顶栏触发删除会话时，系统 **必须** 满足 AC-13c；删除路径 **必须** 与历史窗口（AC-55）在确认策略、不可恢复提示、后端动作上一致（AC-60）。

**AC-14b**（普遍型）：溢出菜单 **必须** 至少含：删除会话、打开 Timeline（Q-4=B 弱化入口）。

**AC-14c**（普遍型）：Tab 超出可视宽度时，系统 **必须** 提供滚动/溢出，使用户仍能到达每一未关 Tab。

**AC-15**（状态驱动型）：多 Tab 时 **必须** 可区分活动与非活动。

**AC-16**（不期望行为型）：系统 **必须不** 以每会话一个 VS Code editor tab 作为主模型（Q-2=A）。

### F2 — 消息流与 Markdown

**AC-20**（普遍型）：系统 **必须** 可区分呈现 user/assistant。

**AC-20a**（状态驱动型）：**在** replay/E2 只读期间，composer **必须** 处于 `readonly`：输入与发送禁用，并提供可见的「继续此对话」CTA（Continue）；**必须不**直接发送新消息；**必须不**仅禁用而无 Continue 入口。

**AC-20b**（状态驱动型）：空或加载中 **必须** 有空态/loading；**必须不**无提示白屏。

**AC-21**（事件驱动型）：**当** settle 时，系统 **必须** 以可读 Markdown 呈现；**必须不**以不可读堆或空白壳收场。

**AC-21a**（普遍型）：Markdown **必须** sanitize；**必须不**脚本注入或未净化 HTML 入 DOM；代码块 **必须** 可读。

**AC-22**（状态驱动型）：streaming 期间 **必须** 有生成中指示；**必须不**展示 thinking（T6）。

**AC-23**（事件驱动型）：**当** I-真 cancel 完成时，系统 **必须** 保留半截（若有）并标已停止，结束 streaming 指示。

**AC-23a**（事件驱动型）：**当** 失败/断连结束时，系统 **必须** 展示可理解原因与可操作提示；**必须不**仅收掉 streaming。

**AC-24**（普遍型）：系统 **必须** 提供跟滚（T7），状态可探针。

**AC-25**（不期望行为型）：**如果** 流式错误/断连，**那么** 系统 **必须** fail-closed 结束 streaming 指示（文案见 AC-23a）。

### F3 — 能力整合入口

**AC-30**（普遍型）：对话流内 **必须** 有活动项（折叠；running|done|failed|aborted）；**必须不**仅依赖 Timeline。

**AC-30a**（事件驱动型）：**当** 展开活动项时，系统 **必须** 展示细节；**必须不**空壳。

**AC-31**（普遍型）：系统 **必须** 展示引用卡（共享解析）；**必须不**仅无纯文本冒充。

**AC-31a**（普遍型）：系统 **必须** 提供引用插入入口；**必须不**仅被动渲染。

**AC-32**（普遍型）：系统 **必须** 提供变更/diff 可见呈现（T8）；权威在 Host。

**AC-32a**（普遍型）：系统 **必须** 提供审阅/撤销可见入口；**必须不**只读无法闭环。

**AC-33**（普遍型）：composer **必须** 覆盖 live/readonly/waiting/error 四态。

**AC-33a**（状态驱动型）：禁用时 **必须** 有可见原因；**必须不**可输入却发送失败无解释。

**AC-33b**（事件驱动型）：**当** 点停止时，控件 **必须** 进入停止中禁用态直至完成/失败；**必须不**重复触发；失败 **必须** 提示。

**AC-34**（事件驱动型）：**当** 重试/编辑重发时，系统 **必须** 走 fork+P-接续；层 B 证明新 sessionId。

**AC-34a**（普遍型）：重试/编辑/分叉 **必须** 在消息/回合上下文可见；**必须不**仅靠命令面板。

**AC-34b**（状态驱动型）：P-接续/标明后，顶栏 **必须** 展示可区分父子关系，父只读可见。

**AC-35**（事件驱动型）：**当** 显式分叉时，系统 **必须** 走 fork+P-标明；层 B 证明新 sessionId。

**AC-36**（事件驱动型）：**当** 复制时，系统 **必须** 送达剪贴板或可观测出口。

**AC-36a**（普遍型）：助手消息与代码块 **必须** 有可见复制入口；**必须不**仅靠手动划选。

**AC-37**（事件驱动型）：**当** 历史/搜索打开时，系统 **必须** 走既有路径；**必须不** auto-Start；**必须不**档 3。

**AC-37a**（事件驱动型）：历史打开 **必须** 只读；已有未关 Tab **必须** 激活既有；**必须不**重复开 Tab。

**AC-38**（普遍型）：顶栏 **必须** 提供搜索档 1+2 主入口 UI，并与历史窗口搜索联动（AC-56）；层 B 证明既有索引。

**AC-38a**（普遍型）：Panel **必须** 提供 Continue 可见入口且与 fork/重试可区分。

**AC-38b**（事件驱动型）：**当** 从历史触发 Continue 时，系统 **必须** same-id resume；**必须不**隐式 fork/重试。

### F4 — 验收

**AC-40**（普遍型）：每 Phase **必须** 层 A + 层 B（若适用）+ 至少 1 条层 V；**必须不**仅层 A/B 宣称 UI 完成。

**AC-41**（普遍型）：层 V **必须** 覆盖：Panel、顶栏、活动 Tab、user/assistant、settle Markdown（若含 F2）、composer 四态可区分。未交付的层 V 项 **必须** 在该 Phase 的 `spec.md` / `verification.md` 标注延至哪一 Phase；**标注延期不得作为该 Phase 的 PASS 依据**（该 Phase 仅可就已交付子集判 PASS）；feature 结束前层 V 清单 **必须** 齐全。层 V 可判定细则见 `ui-visual-spec.md` §9（与 AC-41 联用，非替代）。

**AC-42**（不期望行为型）：**如果** 仅单测绿而层 V 未做或失败，**那么** verifier **必须** FAIL/PARTIAL，**必须不** PASS。

**AC-43**（普遍型）：plan **必须** 2–3 Phase；**必须不** 5+ 细段。

**AC-44**（普遍型）：Timeline **必须** 进一步弱化（Q-4=B）；溢出可打开（AC-14b）；**必须不**恢复长文主阅读面。

**AC-45**（普遍型）：requirements **必须不**含 Should 范围块；凡写入能力 **必须** 有 Must AC；implementer/reviewer **必须不**以「原标 Should」跳过（E14）。

### F5 — 历史窗口与历史会话管理

**AC-50**（普遍型）：Editor Chat Panel **必须** 提供可见的历史窗口（面板内历史列表），并可通过顶栏历史入口打开；该列表 **必须不** 是仅跳转命令面板的 QuickPick。

**AC-50a**（不期望行为型）：**如果** 顶栏历史入口已交付，**那么** 点击后 **必须不** 打开空窗或仅占位；Phase 1 起 **必须** 至少提供基础可浏览列表（可随后 Phase 补齐删除/Continue/父子等完整能力，但入口 **必须** 可用）。

**AC-51**（状态驱动型）：**在** 历史窗口展示条目期间，每个会话条目 **必须** 至少显示：标题、最近活动时间、首条预览（档 1）或关联变更路径（档 2）；**必须不** 显示空标题或无意义占位。

**AC-52**（事件驱动型）：**当** 用户点击历史窗口中的某个会话时，系统 **必须**：若该会话已有未关 Tab 则激活该 Tab；否则以只读 replay 模式打开；**必须不** auto-Start 新会话。

**AC-53**（状态驱动型）：**在** 历史/回放会话已打开期间，系统 **必须** 处于只读模式：composer **必须** 为 `readonly`（输入与发送禁用）并提供可见的「继续此对话」CTA；**必须不** 直接允许发送新消息；**必须不** 仅禁用而无 Continue 入口（与 AC-20a 同锁）。

**AC-54**（普遍型）：历史窗口 **必须** 提供 Continue 可见入口（条目级与/或打开后的 Panel），点击后走 same-id resume；**必须不** 与分叉/重试入口混淆。

**AC-55**（事件驱动型）：**当** 用户在历史窗口（条目 hover/右键或等价条目操作）执行删除会话时，系统 **必须** 弹出确认并提示不可恢复（Q-6=A）；确认后从历史列表移除，若该会话仍有未关 Tab 则同步关闭/移除顶栏 Tab，并更新 persistence/索引；列表 **必须** 实时反映删除结果；删除语义 **必须** 与顶栏（AC-13c）一致（AC-60）。

**AC-56**（事件驱动型）：历史窗口 **必须** 内嵌搜索框，或与顶栏搜索入口联动，支持档 1（标题/预览）与档 2（变更路径）查询；命中结果 **必须** 实时更新；**必须不** 扫正文冒充全文（档 3）。

**AC-57**（状态驱动型）：**在** 历史列表展示 fork 子会话期间，条目 **必须** 显示父会话关系（如「分支自 …」），便于用户识别。

**AC-58**（状态驱动型）：**在** 历史窗口无条目期间，系统 **必须** 显示空态引导；**在** 加载历史期间，系统 **必须** 显示 loading 指示；**必须不** 白屏。

**AC-59**（事件驱动型）：**当** ConversationRegistry 或会话索引发生新增/关闭/删除/父子关系变化时，历史列表 **必须** 实时更新；**必须不** 要求用户手动刷新。

**AC-60**（普遍型）：删除操作在顶栏 Tab（右键菜单与溢出菜单，AC-13c）与历史窗口（AC-55）两处 **必须** 保持一致语义：同一确认策略、同一不可恢复提示、同一后端删除动作；删除后顶栏、历史窗口、Registry、持久化、索引 **必须** 同步更新；**必须不** 两处行为不一致（E16 / Q-6）。
