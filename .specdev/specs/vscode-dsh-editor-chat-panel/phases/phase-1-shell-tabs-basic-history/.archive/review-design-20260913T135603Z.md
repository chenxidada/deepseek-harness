## 关键发现

### 🔴 Must-Fix
（无）— 未发现违反 AD-ECP-* 硬决议或 Constitution §2 的实现。

### 🟡 Should-Fix
1. **Status 行布局对齐 visual-spec §3**：将 `[data-testid="status"]` 移到消息区与 sticky composer 之间，以符合 UI-AC-1 / §3 骨架（当前在 MessageList 之上）。
2. **webview:build 接入扩展构建流水线**：按 AD-ECP-10「扩展编译前/并跑」，在包级 `prepublishOnly` / monorepo host build / CI job 中显式依赖 `webview:build`，避免仅靠手工或已提交 dist 防白屏。
3. **Token 别名与 visual-spec §4 对齐（低优）**：将 `--dsh-button-*` 等与文档 `--dsh-btn-*` / 补齐常用 `--dsh-panel-bg`、`--dsh-radius-*` 别名，减少后续 Phase 样式分叉（功能上已 theme-first，非阻断）。

### 🟢 Observations
- Host 侧未单独建 `chat-panel/bridge/`：符合 design「可选」；attach 内联可接受。
- `btn-overflow` 可见但无菜单：P1 以 Tab 横向滚动满足溢出可达；溢出菜单内容属后续增强，不构成设计违规。
- `btn-search` → QuickPick（`ui/search-open`）：与 P1「入口可见、档1+2 UI→P2」及 GAP-ECP-003 一致。
- 旧 `tests/layer-a/*` 已标注非本 feature UI PASS；RTL 新套件路径正确。
- React 仅 `devDependencies` + 打进 SPA bundle，未污染 Host runtime —— 符合 AD-ECP-8 外部依赖约束。
