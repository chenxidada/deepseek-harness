## 为什么不是 PASS（问题清单）

1. **GAP-CCD-012（AC-4 边界）**：多 root 下发送门禁可经 `preferredFolder` 放行仅存在于非 preferred 根的 `@path`，但 `openReferencePath` 只拼 preferred 根 → 引用卡打开可能误报不存在。独立夹具已复现。残余风险 **MEDIUM**。
2. **GAP-CCD-013（AC-1 边界）**：`prefillComposer` 在 Webview port 未 attach 时发出的 `composer/prefill` 不会被缓冲；`attach()` 不重放 → 冷启动选区预填可能丢失。独立夹具已复现。残余风险 **MEDIUM**。
3. **DEBT-CCD-002（AC-3a 文档 Must）**：AC-3a 要求「文档注明 stub ≠ 真模型」；当前仅有「L2 stub」措辞，未显式声明。功能夹具 ①–⑤ + 独立场景均通过，属文档缺口。残余风险 **LOW**（文档），但与 MEDIUM 边界一并导致不可判 PASS。

主路径（脏保存预填、空选区、@path 门禁无正文注入、空格路径、AC-3a 覆盖矩阵、ide FILE_REFERENCE 挂载、引用卡/meta 行号语义）均有 **L2 执行证据** 通过。
