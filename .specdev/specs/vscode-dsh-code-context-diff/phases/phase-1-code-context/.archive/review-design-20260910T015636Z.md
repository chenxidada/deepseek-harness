## 关键发现

### 🔴 Must-Fix
（无）

### 🟡 Should-Fix
1. **P2-A / AD-CCD-14 文档未回写 `file_path`**：实现已正确以 tool-fs 主字段 `file_path` 做 covering 提取，但 `design.md` AD-CCD-14 仍以 `path`/`file`/`target` 为示例主路径。implementer 受「不改 design.md」约束，偏差已记在 `implementation.md`。**应由调度者补丁 design.md**（声明主字段=`file_path`，aliases 保留），避免 phase-2+ 读者误读 schema。不要求改动产品代码。

### 🟢 Observations
1. AC-3b idle 观测为 grammar / local-provider 模块加载 RSS 代理，非完整 `dsh --profile ide` 长时间 idle；符合「不设硬阈值」精神，implementation 已声明局限。
2. 模块布局、协议扩展、ide mount、命令/菜单接线与 design「文件产出计划」及 phase-1 spec 产出清单对齐。
3. AD-CCD-15 接受整文件 read 已在 `ref-read-coverage.ts` 与 selection 防御路径写明，降低回退内联风险。
