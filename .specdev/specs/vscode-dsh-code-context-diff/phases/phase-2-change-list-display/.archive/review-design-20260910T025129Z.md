## 关键发现

### 🔴 Must-Fix
（无）

### 🟡 Should-Fix
- **Snapshot blob 在 before-cache 未命中时不得回退为 `meta.diffs` hunk 文本。**  
  `change-attributor.ts` `settleTurn`：当 `cachedBefore === undefined` 且 `merge.firstOld !== null` 时，将 `merge.firstOld`（DIFF_CONTEXT hunk）写入 `SnapshotStore.oldText`，而 `newText` 可能已是整文件 after。这违反附录 A.2 / DEBT-001「hunk ≠ blob 载荷」。  
  **建议**：无整文件 before（tool/call 缓存或等价）时 **拒绝写入 blob**（`snapshotRef` 省略 / `available=false`），仍可保留 ChangeRecord 元数据；不要把 hunk 当 oldText 落盘。

### 🟢 Observations
- N=0 对每个定稿 turn 投影一句 `change-list` 空说明：符合 N-1 Must，非架构偏离。
- AC-30 主点击改为 reveal change-list、Timeline 降为次路径：符合 AD-CCD-4；偏差记录正确。
- `pruneToBudget` 暂用 oldest-session：与 phase-3 审阅状态尚未交付一致；session `clearSession` 清目录已具备。
- ChangeStore 现为内存索引：设计允许「扩展 index」；冷回放持久化索引非本 Phase Must。
- design 跨 Phase 计划中的 `revert.ts` 未建：正确推迟到 phase-3。
