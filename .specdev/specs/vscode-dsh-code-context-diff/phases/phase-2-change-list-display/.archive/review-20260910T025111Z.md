## Must-Fix 汇总
1. **AC-12a**：单击变更条目必须 `change/open`（打开文件+定位）；展开 diff 可用独立控件，不可占用主键单击以致 12a 落空。
2. **AC-19**：Webview 发出 `change/reveal-source`；Host 滚到 `data-message-id === sourceMessageId` 的助手气泡（勿滚 change-list）。
3. **AC-30**：`action/reveal-change-list`（或等价）必须携带对应 `sourceMessageId`（或 turn），禁止无 identity 时 `reverse().find` 最近一条。

## Should-Fix 汇总
1. 多 assistant re-anchor 时同步更新 `ChangeRecord.sourceMessageId`。
2. `settleTurn`：无整文件 before 时拒绝写 blob / `available=false`，勿把 hunk `firstOld` 当 oldText。
