### 3. 三类新增「界面相关」接线逐一判定：均非自绘视觉实现

**(a) Output Channel（`HostDiagnosticRecorder` 的 sink）— 不属于自绘 UI**

- `extension.ts:424-426` 通过 `vscode.window.createOutputChannel(HOST_DIAGNOSTICS_CHANNEL_NAME)` 创建，通道名 `'DeepSeek Harness'`（`host-diagnostics.ts:23`）。
- 内容经 `formatHostDiagnosticRecord` 渲染后以 `appendLine` 追加（`extension.ts:430-434`）。
- 该渲染输出为**纯文本键值行**（`host-diagnostics.ts:430-453`：`[dsh] Host start failure #N (phase) — kind` + 缩进的 `time` / `executable` / `exit code` 等），**不含**任何 ANSI 转义、颜色、图标或主题 token。
- Output Channel 是 VS Code **原生面板**，扩展不掌握其排版与配色（由用户主题决定）。扩展侧提供的仅是文本内容，不构成自绘界面。
- 入口 `dsh.showHostDiagnostics`（`extension.ts:537-540`）只调用 `hostDiagnosticsChannel?.show()`，不创建视图、不注入 HTML。

**(b) 状态栏重试入口 — 沿用既有实现，本 Phase 未触碰**
