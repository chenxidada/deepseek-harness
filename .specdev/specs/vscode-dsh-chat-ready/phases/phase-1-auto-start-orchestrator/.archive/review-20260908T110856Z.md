## Must-Fix 汇总

1. **AC-1e / AD-CR-9 — `dsh.deleteHistory` 离线不得静默失败**
   - 现状：`deleteHistorySession`（或等价）在 Host 未连时只 `return { outcome: 'host-not-ready' }`，无用户可见提示，菜单未禁用。
   - 要求：与 `deleteConversation` / `runDeleteActive` 对齐——禁用或明确提示「Host 连接后可删除」；**不**完整自动建连；**不**假删权威。
   - 测试：L2 覆盖 `dsh.deleteHistory` 离线路径（断言提示或禁用 + `start` 未调用）。

## Should-Fix 汇总（本轮可不挡回炉，建议顺手修）

1. **AC-1b**：生产活动栏打开信号弱（偏差 2）；可见性路径仍通。
2. **AC-13**：connecting 投影缺专用 L2 断言。
3. **连通性**：Webview `action/continue` 不走 `ensureHostForSend`（命令路径会 auto-start）。
