### 🟢 Observations
- **Host server 实现落在 `ide-bridge` 包、由 Extension 驱动 listen**：组件图把 `BridgeHostServer` 画在 Extension 侧，包表强调 bridge 为「socket 客户端」。当前把共享 UDS/NDJSON 与 `IdeBridgeHostServer` 放在 `ide-bridge`、由 `IdeSessionHost` 拥有 listen 生命周期，符合 Q-1「包树可迁、契约不变」，且与 Extension「bridge server listen」产出一致。
- **Answerer stub 无 ACP 式 agent 所有权过滤**：Phase 1 对所有 `approval/request` / `user-questions/request` 终端认领并 fail-closed，与「ide 单进程唯一 Host 应答」及 Phase 3 STUB 范围一致；AD-4 的 owned/`next()` 细分应在填实 STUB 时对齐 ACP。
- **`IdeBridgeTransport` 可替换接口未单独抽出**：AD-8 / Phase 5 的替换证明尚早；现有 Host/Client + NDJSON 已构成可换传输的实质骨架。
- **AC-5 以静态 patch 断言落实**：spec 允许「组合测试或 boot 断言」；未做 Loader 启动时扫描冲突行，与 design「启动时组合校验」字面略宽，但未偏离 Phase 1 验收与探索报告建议。
