# Phase 1 验证报告

## 判决：PARTIAL

主路径（ide profile 启动、SDK stdout JSON-RPC、Host bridge UDS hello、`initialize` 门闩、`shutdown`、Web 互斥、env 密钥 redact）均有真实执行证据，含 **verifier 自建端到端**。未阻塞的 SHOULD-FIX / Known Gaps（GAP-001、GAP-002）仍在 → 按规范判 **PARTIAL**（非 FAIL：必达 AC 未断裂；非 PASS：有未解决 gap）。

## 为何不是 PASS（问题清单）

1. **GAP-001（AC-32 边界）**：`redactSecrets` 只扫描 Extension `process.env`；仅经 `credentials` 注入且未出现在父进程 env 的密钥，若进入错误文案则不会被 redact。独立脚本 `V-U-1` 复现。主路径 env 密钥仍可 redact（`V-U-2`）。
2. **GAP-002（AC-3 测试薄）**：成功 `shutdown` → `disconnected` 缺 IdeSessionHost 单测；行为由 e2e/`deactivate` 路径覆盖，非功能断裂。
3. **STUB-001 / STUB-002**：已登记、目标 Phase 3、🟡非阻塞；参数变化仍 fail-closed，不阻断本 Phase 必达路径。
