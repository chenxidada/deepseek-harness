## 主动问题上报（AC-19）—— 为何不是 PASS

本 Phase 判决为 **PARTIAL**，根因**已从「环境缺 key」转变为「带 key 真机暴露的真实缺陷」**。分条如下：

1. **AC-5（DEBT-3）未彻底达成**：隔离 2 次（本轮另 1 次复跑 = 3 次）均 pass，但全链 model 批中 `cap-message-store-stream-patch` 以 `no streaming increment observed` 失败。`intervalMs:150→50` 只降低了波动概率、未消除。AC-5 的「不再跨 run 波动」验收未达成 → 残余风险 MEDIUM，DEBT-3 维持活跃（已改目标Phase「后续 Phase」）。
2. **`cap-selection-ask` 可复现失败（新增 DEBT-14）**：`assistant-replied`（`$assistantContains:LAYER-V-CAP-26-OK`）连续 2 次超时。这是 DEBT-12 修复 readonly-live 后**首次暴露**的真实缺陷——此前该能力被污染② 遮蔽、从没跑过真实路径。panelSnapshot 证据显示 selection-ask 会话未成为 active tab。**不在本 Phase 声明范围，但影响 AC-9 全链 exit 0**。
3. **`cap-messages-protocol` 流式波动（新增 DEBT-15）**：`requireIncrement:true` + `intervalMs:150`（本 Phase 未改），全链 fail / 隔离 pass，与 DEBT-3 同根因。暴露「流式增量可观测性」是**系统性问题**，不止 #18 一项。
4. **AC-9 全链 exit 1（非 0）**：42 项串行跑完，但 exit 1 由 DEBT-2/3/14/15 四项真实失败贡献。**DEBT-12 的污染隔离本身已修复**（零 readonly-live、exit 1 非串行污染），故「exit code 反映真实结论」达成，但「一键跑通 exit 0」未达成。

以上 1-3 均为**实现层缺陷/残留**（非环境约束）；其中 DEBT-10/DEBT-12 两条核心债务真机确认闭环，是明确的正面结论。
