## 关键发现

### 🔴 Must-Fix

无。

### 🟡 Should-Fix

1. **钉住「运行中」子会话会建成可写 `live` Tab，偏离 AD-CU-11「运行中只读实时」**
   - 位置：`conversation-controller.ts:1856-1857`（`pinSubagent` 内 `const mode: OpenTabMode = run === 'running' ? 'live' : 'replay'`）。
   - 现象：从运行中子会话的面包屑点「钉住」（`TabChrome.tsx:365-378` 只判断 `contextSessionId !== undefined`，不区分 running/replay）时，`registry.create(..., mode='live')` 产出 status=`idle`、mode=`live` 的子 Tab；随后 `resolvePanelProjection` 对该子 Tab 投影为 `'live'`（`contextSessionId` 已清空，走根分支 `:1911-1918`），`sendPrompt` 放行发送。这与上下文进入路径的运行中→`readonly-live`（只读）行为不一致。
   - 性质：这是 Should 级窄路径（AC-38「钉 Tab」本身是 Should；钉运行中场景更窄），且根因是设计数据模型 `OpenTabMode` 只有 `'live'|'replay'`、无 Tab 级「只读 live」态——design.md 未定义运行中钉 Tab 的 Tab 级表示。实现以 `onSubagentFinished` 对 `live` 子 Tab 强制 `setMode('replay')`（`:2042-2046`）兜底，说明其内部模型是「运行中=live、结束=replay」而非静默断裂。
   - 建议：a) 钉运行中子会话时将其投影为 `readonly-live`（或复用 `childRunState` 在 `resolvePanelProjection` 对 `pinnedSubagent` 且 running 的子 Tab 返回 `readonly-live`）；或 b) 在 `design.md` 记录「钉 Tab 后子会话即升格为可写 live」的显式偏差并同步 AC-71 语义。二选一，避免「同一运行中子会话，上下文路径只读、钉 Tab 路径可写」的口径分裂。

### 🟢 Observations

1. **`isProjectedSession` 语义 vs 命名**：私有助手 `isProjectedSession(active, sessionId)`（`:2060-2063`）返回 `active.sessionId === sessionId || active.contextSessionId === sessionId`，即「Tab 根或当前子上下文」，而非常规「当前正在投影」语义。其 JSDoc 已说明含义；但需注意：在子上下文投影期间，父根 session 的新消息会命中该助手 → 走 `pushAppend`/`pushPatch` → 被 `chat-panel-host.projectedSessionId()` 精确过滤掉（`chat-panel-host.ts:974-980`），因此**父根新消息在子上下文期间既不推送也不标 unread**。这是行为语义（偏 correctness）而非架构违背，仅提示命名与「根或上下文」的语义略有出入。

2. **父边双来源查找**：`navBack`/`resolvePanelProjection`/`teardownDeletedSession` 均用 `timeline.getParent(sessionId) ?? index.read().sessions.find(...).parentSessionId` 双来源兜底（`:1814-1815`、`:1905-1906`、`:1594-1595`）。这是对「TimelineStore 边为进程内、index 边为持久化恢复」两种真相源的合理调和，与 repo-exploration §4.1/§6 一致，非重复造边。

3. **`--dsh-bubble-notice` token**：`SubagentCard` 引用 `var(--dsh-bubble-notice, var(--dsh-bg))`（`MessageList.tsx:542`）。该 token 未在 `webview/src/styles/tokens.css` 中定义为显式变量（仅靠 fallback `--dsh-bg`）。属视觉/token 层小项，不构成本视角判决。

4. **文案硬编码**：新增中文文案（「子代理运行中 — 只读直播」「子会话已删除」等）与既有 webview 组件（`分支自 …`、`可继续`）同为硬编码中文，未走 locale 字典。与该 app 现存约定一致，非本 Phase 新引入的偏差。
