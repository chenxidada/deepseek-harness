## 术语（全文统一）

| 术语 | 含义 | 首次括注 |
|------|------|----------|
| **权威会话日志** | DSH 侧会话正文与可回放历史的唯一权威源 | authoritative session log |
| **扩展索引** | 扩展本地维护的工作区会话元数据、未关 Tab 集、活动 Tab、UI 偏好等非正文索引 | extension index |
| **回放视图** | 从权威会话日志重建的只读会话呈现（面板消息流 + Timeline 调试投影）；输入禁用 | replay view |
| **live** | 可对会话发送 prompt 的可交互视图上下文 | — |
| **未关 Tab 集合** | 扩展索引中记录的、用户尚未关闭的 Conversation Tab 身份集合（含回放 Tab） | open-tab set |
| **L1** | Node/vitest/fake SDK·bridge：库与控制器契约测（必要但不充分） | verification L1 |
| **L2** | 扩展测试宿主（优先 `@vscode/test-electron` 或设计选定的等价 Extension Host runner）：激活扩展、命令 API、会话/Tab/索引行为的可脚本自动证据 | verification L2 |
| **L3** | Webview 消息契约自动证据（postMessage 往返：`composer/send`、`ui/reject-send`、`messages/*`、`panel/state` 等） | verification L3 |
| **L4** | 真人点击 UI / 人工探索：仅可作辅助，**不得**作为产品 Phase 判 PASS 的唯一或主要证据 | verification L4 |

下文优先使用上表中文术语；旧称 session log / history（作正文库义）一律理解为**权威会话日志**；扩展侧「历史列表」指基于**扩展索引**的 UI，非第二正文权威。

## 产品目标

在已交付的 VS Code「窗口壳」（多 Tab、SDK+Host bridge 双通道、Timeline TreeView、fail-closed 审批/提问、事后 Diff、AD-8 可替换契约）之上，交付**真正的会话/聊天面板**作为主阅读与人机输入面；将 Timeline **弱化为** turn/step/tool/status/subagent/Diff 调试面（短 label + 可定位）；支持**父→子会话可进入**（运行中为只读实时投影）；把关 Tab 默认策略从「dispose」改为**卸 UI、权威会话可恢复**；并交付当前工作区的**历史列表 + 回放视图 +（Should）继续此会话**，以及重启后恢复上次未关 Tab 集——**不重做** agent-loop、双通道与 AD-8 权威文档。

## 问题陈述

前序 feature `vscode-dsh-ide` 已合入 master，提供多会话窗口壳与双通道。本地验证暴露两类产品缺口：

1. **没有真正的对话面板**——Timeline 上的 assistant 截断行被误用成阅读面，无法像聊天面板一样阅读与发送。
2. **关 Tab = 结束会话**——`apps/vscode-dsh/README.md` 当前默认：关闭 Tab 发送 bridge `session/dispose` 并清除会话；历史不可恢复，重启无法带回未关 Tab。

| 表面 | 现状（前序交付） | 本 feature 要解决 |
|------|------------------|-------------------|
| Conversations | TreeView Tab 栏 | 仍为 Tab 身份栏；面板内容随活动 Tab 切换；关 Tab 策略**改为可恢复**；历史打开占 Tab |
| Timeline | turn/step/tool/**assistant 截断摘要** | **弱化**：不再展示 assistant 长文；短 label；点击可定位对话面板；Diff 入口保留在工具行 |
| Prompt 入口 | 命令 + toast | 面板输入发送为人机主入口；命令并存 |
| 审批 / 提问 | QuickPick / InputBox | 保留；面板做等待可见；非活动 Tab 审批角标；会话↔交互绑定防错配 |
| Chat Webview | **不存在** | Must：消息流主阅读面 |
| 关 Tab | **dispose 结束会话** | **改为**卸 UI、权威保留；显式「删除会话」才 dispose；删除关闭已打开视图 |
| 历史 / 重启 | 无工作区历史列表、无回放 | Must：历史列表（可独立于 Host）+ 回放视图 + 重启恢复未关 Tab（先只读；Host 未连时等待） |
| Subagent | Timeline 嵌套标记 | Must：可进入子会话（运行中只读实时投影 → 结束后自动回放） |

本 feature **明确改变**前序 `vscode-dsh-ide` 的默认关 Tab 策略（dispose → 可恢复），并要求回归：**显式删除**仍能彻底结束权威会话。

## 目标终态

开发者在同一 VS Code 窗口 / 当前工作区中：

- **对话面板**是 user/assistant 消息流的**主阅读面**与人机主输入面；Timeline 仅作调试/步骤/工具/Diff 面，**不再**以 assistant 截断行充当对话阅读；Timeline 短 label 可点击定位到对话面板对应消息。
- 可从父会话消息流中的 subagent 卡片**进入**子会话视图，经面包屑返回；子会话默认不占 Conversations Tab；运行中进入 = 只读实时投影，结束后自动转为回放视图。
- **关闭 Tab** = 卸除该会话 UI；权威会话日志保留，可从历史再次打开（回放视图）。**删除会话**才 dispose + 清权威，并关闭该会话已打开的 live/回放 Tab。
- 关 Tab 时若会话仍在 running：弹出确认——「停止并关闭」或「取消」；文案标明「停止」**不可逆**（损失进行中回合）。不把「后台跑完再变历史」列为 Must（S-20 Out）。
- **历史列表**（仅当前工作区，基于扩展索引，可独立于 Host）展示标题、mtime、可选续写能力元数据（可同 id 续写 / 仅派生续写 / 未知）、可选首句摘要；**必须不**使用含糊的「只读/可继续」二元标；打开历史 = **一律先创建/激活回放 Tab**（输入区禁用，明确「回放中」）；「继续」是否可用由 T-0b + 能力探测决定；若目标会话已有 live/回放 Tab 则激活已有，不叠副本。
- **（Should）** 回放顶栏「继续此会话」→ 优先同一 `sessionId` 在权威会话日志上续写；不得篡改已落盘旧前缀；若被迫派生新会话则 UI 标明「新会话 · 接续自 …」。含继续的 Phase 须先过 **T-0b**；含历史回放重建的 Phase 须先过 **T-0a**。
- **重启/重开 host** 后自动恢复上次未关的 Tab 集合；各 Tab **先只读回放**；Host 未连时显示等待态，就绪后自动重建；扩展索引**保留全部**未关 Tab 身份；UI 可只恢复最近 N 个（**上次活动 Tab 恒优先纳入**，再补最近 N−1）并提供「查看更多 / 全部恢复」；未进 UI ≠ 丢弃索引；自动聚焦上次活动 Tab。
- **删除边界**：非 running 删除须简单确认（确认前不 dispose）；running 删除须确认「停止并删除」/「取消」（确认前不 dispose）；Host 未就绪时删除入口禁用或标明「Host 连接后可删除」（禁止仅清索引造成删除假象）；子已删→父卡片「子会话已删除」；父已删→子面包屑「父会话已删除」。
- **空 Tab 关闭**：无实质消息时关 Tab → 不进历史、不 dispose、不无故确认。
- **回放→live**：同一 `tabId` 原位升级 mode；禁止同会话双 OpenTab（replay+live）；Continue 成功后才改 mode；派生可同 tabId 换绑 sessionId。
- **回放边界**：Timeline Diff 仅权威日志含可恢复补丁/快照时可用；不完整回合标「已停止/未完成」；子会话已钉 Tab 后从父进入须激活已有子 Tab。
- 消息/历史权威 = **权威会话日志**；扩展只投影 + 维护**扩展索引**与 UI 偏好；live MVP 助手输出以完整消息追加，运行中须有生成中指示（流式 Could）。
- 审批/提问仍走 Host bridge + 现有 InteractionUi；维护会话↔待处理交互关联；交互 UI 可串行（活动 Tab pending 优先；队头结束后立即下一项；切 Tab 可唤起该 Tab pending）；**不**因切 Tab/叠盖导致回传错配或静默丢失；**不**用 Webview 重做完整审批表单作 Must。
- **不**修改 `packages/core/agent-loop`；不重做双通道 / ide profile / AD-8。

## 预期范围

### In Scope（Must）

- **对话面板 UI**（Webview 或等价）：活动（或当前面板上下文）会话的消息/回合流主阅读面。
- **Timeline 弱化**：Timeline **不**再展示 assistant 长文；长文只在对话面板；Diff 入口仍在 Timeline 工具行；turn/tool 保留短 label。
- **面板输入发送**：对人机主入口；目标为活动 live Tab 的 `sessionId`；复用既有 `session/prompt` 缝。
- **关 Tab 可恢复（改变前序默认）**：关 Tab = 卸 UI；权威会话日志保留；**非**默认 dispose。
- **显式删除会话**：dispose + 清权威；关闭该会话已打开的 live/回放 Tab；从未关 Tab 集合与历史可打开集合移除；删除入口在历史列表行与回放顶栏均可发现；父删**不**级联删除子权威（钉成的子 Tab 关闭；子权威仍可单独在历史中存在/删除）；**非 running 时**须简单确认，确认前**必须不** dispose（AC-81）；**running 时**须确认「停止并删除」/「取消」，确认前**必须不** dispose（AC-72）；Host 未连接/未就绪时删除入口禁用或标明「Host 连接后可删除」，**必须不**仅清扩展索引而保留权威造成删除假象；子已删/父已删导航见 AC-74/75。
- **关 Tab + running**：确认框——停止并关闭 / 取消；文案标明「停止」不可逆。
- **空 Tab 关闭**：无实质消息时关 Tab → 不进历史、不 dispose、不无故确认（AC-82）。
- **Session 留存**：当前工作区历史列表（扩展索引；可独立于 Host；标题、mtime、`continueCapability` 展示映射、可选首句摘要；**无**「只读/可继续」二元标）+ 打开恢复。
- **历史打开 = 回放视图 Tab**：一律先创建或激活回放 Tab；输入区禁用，明确「回放中」；从权威会话日志重建面板 + Timeline；计入未关 Tab 集合；已有 live → 激活 live；已有回放 → 激活回放（不叠副本）；同会话窗口内同时只能有一个 live 视图；Continue 成功后同一 tabId 原位 replay→live；回放 Diff / 不完整回合见 AC-76/77。
- **重启恢复**：恢复上次未关 Tab 集合为只读回放；Host 未连时「等待 Host」；就绪后自动重建；扩展索引保留全部未关 Tab 身份；UI 可只恢复最近 N 个（上次活动 Tab 恒优先 + 最近 N−1）并提供「查看更多 / 全部恢复」；未进 UI ≠ 丢弃索引；自动聚焦上次活动 Tab。
- **对话面板消息流（live MVP）**：助手消息以完整消息追加；运行中须有可见生成中指示；流式增量刷新保持 Could（AC-55）。
- **Subagent 可进入**：父流卡片 → 子会话视图；面包屑回父；默认不占 Tab；运行中进入 = 只读实时投影，结束后自动转为回放视图；父面板「子代理运行中」（子结束且父为当前上下文时清除）；子会话回放/继续策略与父相同（P1-A）；已钉 Tab 后进入须激活已有子 Tab（AC-78/79）。
- **多 Tab**：非活动新消息未读点（激活且面板已展示后清除）；非活动审批角标；会话↔待处理交互关联；交互 UI 可串行呈现（活动 Tab pending 优先；队头超时/fail-closed/Abort 后立即下一项；切 Tab 可唤起该 Tab pending）且不得错配/静默丢失；并行 running 各 Tab 独立 busy，面板只显活动 Tab 状态。
- **权威边界**：消息/历史权威 = 权威会话日志；扩展只投影 + 扩展索引 + UI 偏好；回放重建后消息条数/顺序/角色与 Timeline turn/tool 可与权威日志逐项比对。
- **审批等待可见**：面板等待态；应答仍 Host bridge + InteractionUi；**不**重做审批表单作 Must。
- **边界**：不改 `packages/core/agent-loop`；不重做双通道 / ide profile / AD-8；可编程 prompt 与面板并存。
- **回归**：显式删除仍能结束会话；Conversations / Timeline（弱化后）/ Diff / permission / 审批 fail-closed 仍可验证。
- **验证路径覆盖**：feature 交付结束前，e2e 路径清单**必须包含**「重启恢复 Tab 集」「进入子会话（运行中或回放）」并至少各覆盖一次（可跨 Phase）；产品 Phase 的独立 e2e **必须**可在 **L2** 扩展宿主脚本执行（见 AC-54 / AC-84），**不得**仅靠 L1 或人工 L4 达标。

### In Scope（Should）

- **P1-A 继续此会话**：回放顶栏动作 → 转为可 `session/prompt` 的 live Tab；优先同一 `sessionId` 续写权威会话日志；不得改写已落盘旧前缀；若只能派生则标明「新会话 · 接续自 …」；**实施前须过 T-0b Spike Gate**（阻塞含「继续」的 Phase；**不**阻塞纯只读回放 Phase）。
- Timeline 短 label **点击定位**到对话面板对应消息（优先序见 AC-56）。
- 面板内轻量「本回合改了 N 个文件」类摘要，可链到 Timeline/Diff。
- 子会话可「钉成 Tab」（钉后从父进入激活已有子 Tab；钉定时若正处子上下文则提升并恢复父视图）。
- Tab 标题使用 session/title 或首条用户消息。
- 扩展索引「已删除」墓碑 GC（有引用保留；无引用超窗口可清）（AC-83）。
- 可编程命令入口与面板并存（面板 = 人机主入口）。

### In Scope（Could）

- Streaming markdown / 代码高亮 / 气泡级 Chat UX。
- 面板内工具调用摘要卡片（不替代 Timeline）。
- 从面板一键唤起既有审批 QuickPick。
- 关 Tab 时「后台继续跑完再变历史」（**默认 Out**；仅当用户后续明确纳入）。

### Out of Scope（本 feature）

- Spec 驱动面板、hooks 策略包产品化。
- 重做双通道、`ide` profile、stdout/bridge 分离、AD-8 权威替换契约文档。
- 修改 `packages/core/agent-loop`；扩展内重实现 agent 循环 / 工具执行 / **另立**聊天正文库作为权威。
- 用 Webview **重做**完整审批/提问表单替代 QuickPick（等待态可见为 Must）。
- Cursor 级完整 Chat UX 作为 Must。
- GAP-010 / GAP-011——默认不纳入。
- Fork Code-OSS；以 ACP 为主协议；非程序员全自动模式。
- 跨工作区统一历史列表（历史 **仅**当前工作区）。
- 需求中规定具体 RPC 方法名作为验收契约（能力与验收写清即可；RPC 选型留给 plan-generator）。
- S-20「关 Tab 后台跑完再变历史」——**保持 Out**。
- 临时 peek 历史（不占 Tab）——本版无；历史打开一律占 Conversation Tab。
- 以当前工作区内容冒充历史 Diff 快照——**禁止**（见 AC-76）。

## 功能区域

### F1. 对话面板壳与消息流

- 注册可打开的对话面板；与 Extension Host 通信。
- 展示当前面板上下文（活动 Tab 或进入的子会话）的 user/assistant 消息流。
- live MVP：助手消息以完整消息追加；运行中展示生成中指示；流式增量刷新为 Could。
- 空态 / host 未连接引导；内容来自权威会话日志投影，不臆造助手正文。

### F2. 输入、发送与回放模式（P1-A）

- Live：输入区 + 发送 → 活动 live `sessionId` 的 prompt 路径。
- 回放视图：输入禁用 + 「回放中」标识；**必须不**对只读回放会话发出 prompt（拒绝须有可感知反馈；需求不绑定协议消息名）；不完整回合标「已停止/未完成」；Diff 仅权威含可恢复快照时可用。
- Should：顶栏「继续此会话」→ 同 tabId 原位转 live（成功后才改 mode；同 id 续写优先；不得改写旧前缀；派生须标明且可同 tabId 换绑）；**T-0b** Spike Gate 见开放问题 / 风险；能力探测决定「继续」可用性。

### F3. Timeline 弱化与分工

- Timeline：turn / step / tool / status / subagent / Diff；**不**展示 assistant 长文；保留短 label。
- Diff 入口仍在工具行；**回放视图中** Diff 仅在权威会话日志含可恢复补丁/快照时可用，否则禁用并说明（**必须不**以当前工作区冒充历史 Diff）。
- Should：点击 Timeline 条目定位对话面板对应消息；面板内轻量改动摘要链到 Timeline/Diff。
- 文档化面板 vs Timeline 职责，避免双「主阅读面」。

### F4. 关 Tab / 删除 / running 确认

- 关 Tab = 卸 UI；权威保留；可从历史打开。
- **空 Tab 关闭**：无实质消息 → 不进历史、不 dispose、不无故确认（AC-82）。
- 删除会话 = dispose + 清权威 + 关闭已打开 live/回放 Tab + 从未关 Tab 集合与历史可打开集合移除。
- **非 running 删除**：简单确认；确认前必须不 dispose（AC-81）。
- **running 删除**：确认「停止并删除」/「取消」；文案标明停止不可逆、将丢失进行中回合；**确认前必须不 dispose**（与 AC-72 对齐）。
- **Host 离线删除**：Host 未连接/未就绪时删除入口禁用或标明「Host 连接后可删除」；**必须不**仅从扩展索引移除而保留权威会话日志（删除假象）。
- 父删子：不级联删除子权威；钉成的子 Tab 关闭；子权威可单独在历史存在/删除；父已删时单独打开的子会话面包屑「父会话已删除」且禁用返回。
- 子已删：父上下文 subagent 卡片显示「子会话已删除」、不可进入；父其余内容不受影响。
- running 关 Tab = 确认停止并关闭（标明停止不可逆）/ 取消。
- 删除入口：历史列表行与回放顶栏均可发现。
- （Should）墓碑 GC：有引用保留；无引用超窗口可清（AC-83）。

### F5. 历史列表与重启恢复

- 仅当前工作区；基于扩展索引；可独立于 Host 展示。
- 列表：标题、mtime、`continueCapability` 展示映射（same-id / derive-only / unknown·FAIL 不暗示可继续）；**无**「只读/可继续」二元标；打开一律先回放。
- 打开 = 创建/激活回放 Tab（重建面板 + Timeline）；计入未关 Tab 集合。
- 同会话已有 live → 激活 live；仅有回放 → 激活回放；Continue 成功 → 同 tabId 原位 replay→live（禁双 OpenTab）。
- Host 未连时打开/恢复 → 「等待 Host 连接/启动」；就绪后自动重建回放视图。
- 重启/重开 host：扩展索引保留全部未关 Tab 身份；UI 可只恢复最近 N 个（上次活动 Tab 恒优先 + 最近 N−1）并提供「查看更多 / 全部恢复」；未进 UI ≠ 丢弃索引；聚焦上次活动 Tab。
- 含「历史回放重建消息流 + Timeline turn/tool」的 Phase 须先过 **T-0a**；纯 live 面板可不被 T-0a 阻塞。

### F6. Subagent 进入

- 父流卡片进入子视图；面包屑回父；默认不占 Tab；Should 可钉 Tab。
- 运行中进入 = 只读实时投影；结束后自动转为回放视图（无需用户重新进入）。
- 进行中父面板「子代理运行中」；子结束且父为当前上下文时清除；回放/继续策略同 P1-A。
- 子会话**已钉成 Tab** 后，从父卡片进入 → **必须**激活已有子 Tab，**必须不**在父 Tab 内再切换为该子会话上下文。
- 「钉成 Tab」时若当前面板上下文正处于该子会话 → **必须**将该上下文提升为独立 Tab，并将父 Tab 恢复到父会话视图（与 AC-59 单 live 一致）。

### F7. 多 Tab 未读与审批角标

- 非活动新消息：未读点，不抢焦点；Tab **激活且面板已展示该会话**后清除。
- 非活动审批：角标 + 可切到该 Tab；维护会话↔待处理交互关联；交互 UI 可串行（活动 Tab pending 优先；队头超时/fail-closed/Abort 后立即下一项；切 Tab 可唤起该 Tab pending）；当前弹层指示所属 Tab/会话；**必须不**因切 Tab/并发未决/叠盖导致回传错配或静默丢失。
- 并行 busy：各 Tab 独立；面板只显活动 Tab。

### F8. 权威与扩展本地存储

- 权威 = 权威会话日志。
- 扩展最多存：未关 Tab 集合、活动 Tab、工作区扩展索引、UI 偏好、继续派生时的新旧关联；**不当**聊天正文库。
- 回放视图 = 从权威会话日志重建；消息条数/顺序/角色与 Timeline turn/tool 可逐项比对；需求不绑定具体 RPC 名。

### F9. 与既有壳共存

- 双通道、fail-closed、Diff、permission-presets、AD-8 继续有效。
- 不改 agent-loop。

## 验收标准（EARS 格式）

优先级：`[Must]` / `[Should]` / `[Could]`。每条可独立判 ✅/❌。  
**产品决策已全部锁定**；下列 AC 以锁定决策为准，并合并评审缺口 P0+P1+P2。

### A. 对话面板存在、空态与消息流

**AC-1:** `[Must]` **普遍型** — 系统 **必须** 在 VS Code 中提供可打开的对话/聊天面板（Webview 或等价持久面板），作为 user/assistant 消息流的**主阅读面**；**必须不** 仅依赖 toast / InformationMessage / Timeline assistant 截断行作为对话阅读面。

**AC-2:** `[Must]` **状态驱动型** — **在** 尚无活动对话 Tab 或 IDE session host 未连接 **期间**，对话面板 **必须** 展示可理解空态或引导；**必须不** 呈现其他会话的残留消息。

**AC-3:** `[Must]` **事件驱动型** — **当** 开发者新建对话 Tab 且该 Tab 成为活动 Tab **时**，对话面板 **必须** 绑定到该 Tab 的会话身份，展示空消息流（或「尚无消息」），且（在 live 模式）输入目标指向该会话。

**AC-4:** `[Must]` **事件驱动型** — **当** 活动上下文产生可投影的用户消息/已入队 prompt 事实 **时**，对话面板 **必须** 以可读形式展示该用户内容（可滚动全文）；**必须不** 仅用 Timeline 式短截断作为唯一展示。

**AC-5:** `[Must]` **事件驱动型** — **当** 该会话在 **live** 模式下发出可投影的助手输出事实（回合完成或等价可落盘助手消息）**时**，对话面板 **必须** 以**完整消息**追加展示对应助手文本，并归属到当前面板上下文的消息流；MVP **必须不** 将「分片/增量流式刷新助手气泡」列为 Must（流式仍见 AC-55 `[Could]`）。

**AC-6:** `[Must]` **普遍型** — 对话面板展示的消息内容 **必须** 来自权威会话日志的投影（经既有 SDK 通知/扩展侧投影）；**必须不** 由扩展臆造未出现在权威投影中的助手正文。

**AC-7:** `[Must]` **状态驱动型** — **在** 会话处于忙碌、生成助手输出或等价运行中 **期间**，对话面板 **必须** 展示可见的「正在生成…」或等价运行中/生成中指示，并在回到空闲或助手完整消息已展示后清除。

**AC-8:** `[Could]` **可选功能型** — **若** 启用 Markdown/代码块渲染，系统 **必须** 仅渲染来自投影的文本；**必须不** 因渲染失败而阻断纯文本回退阅读。

### B. 面板输入、发送与命令并存

**AC-9:** `[Must]` **普遍型** — 对话面板 **必须** 在 **live** 模式下提供文本输入区与明确发送动作，使开发者无需打开 Command Palette 即可提交 prompt。

**AC-10:** `[Must]` **事件驱动型** — **当** 开发者在 live 面板对活动 Tab 提交非空文本 **时**，扩展 **必须** 对该 Tab 绑定会话调用既有 prompt 入队路径，获得成功入队信号，并在面板反映已发送/已入队。

**AC-11:** `[Must]` **不期望行为型** — **如果** 输入为空（仅空白）、当前无活动 live 会话、面板处于回放/空态、或 host 未就绪，**那么** 系统 **必须** 拒绝发送并给出可感知反馈（反馈路径由 Host/面板协商，需求 **必须不** 绑定具体协议消息名）；**必须不** 静默丢弃。

**AC-12:** `[Must]` **普遍型** — 面板发送路径 **必须** 复用 `apps/vscode-dsh` 既有会话驱动缝；**必须不** 在扩展内另立第二套 agent 循环。

**AC-13:** `[Should]` **普遍型** — 系统 **应该** 保留可编程 prompt 入口（现有 `dsh.promptActiveConversation` 或文档化等价），与面板人机主入口并存。

### C. Timeline 弱化（C1–C3）与定位

**AC-14:** `[Must]` **普遍型** — Timeline **必须不** 再展示 assistant 长文/长摘要作为对话阅读替代；助手正文的主阅读位置 **必须** 是对话面板。

**AC-15:** `[Must]` **普遍型** — Timeline **必须** 继续承载 turn / step / tool / status / subagent 调试信息（条目保留短 label，无长文），且写/编辑类工具行 **必须** 仍提供既有事后 Diff 入口。

**AC-16:** `[Should]` **事件驱动型** — **当** 某一回合产生可统计的文件改动 **时**，对话面板 **应该** 展示轻量摘要（例如「本回合改了 N 个文件」），并提供链到 Timeline 对应行或 Diff 的入口。

**AC-17:** `[Should]` **普遍型** — 系统 **应该** 在扩展文档中写明：对话面板 = 主阅读面；Timeline = 调试/步骤/工具/Diff 面。

**AC-56:** `[Should]` **事件驱动型** — **当** 开发者点击 Timeline 中某一 turn/工具等短 label 条目 **时**，系统 **应该** 将对话面板滚动/定位到对应消息，定位优先序为：（1）若点击工具类条目 → 定位到触发该工具的 **user** 消息；（2）否则定位到该 turn 的 **assistant** 消息；（3）若仍无可定位目标 → 给出可预测的「无可定位」反馈（或等价），且 **必须不** 串台到其他会话。

### D. Conversation Tab 联动与多 Tab（E1–E4）

**AC-18:** `[Must]` **事件驱动型** — **当** 开发者切换活动 Conversation Tab **时**，对话面板 **必须** 将消息流与（live 时）发送目标切换到新 Tab；**必须不** 把随后输入发到切换前的会话。

**AC-19:** `[Must]` **事件驱动型** — **当** 非活动 Tab 的会话产生新消息 **时**，系统 **必须** 在该 Tab 上展示未读指示；**必须不** 自动抢夺焦点或把这些消息写入当前活动面板流。

**AC-57:** `[Must]` **事件驱动型** — **当** 某一 Conversation Tab 成为活动 Tab **且** 对话面板已展示该会话内容 **时**，系统 **必须** 清除该 Tab 的未读指示；仅 Tab 激活但面板尚未展示该会话内容 **必须不** 视为已读清除条件已满足。

**AC-20:** `[Must]` **事件驱动型** — **当** 非活动 Tab 的会话出现待处理审批/提问 **时**，系统 **必须** 在该 Tab 上展示角标或等价可见提示，并允许开发者切换到该 Tab；应答 **必须** 仍经由既有 QuickPick/InputBox（或既有 InteractionUi）；系统 **必须** 维护「会话 ↔ 待处理交互」关联。

**AC-58:** `[Must]` **不期望行为型** — **如果** 存在切 Tab、多个未决交互并发、或弹层叠盖，**那么** 系统 **必须不** 将结局回传到错误会话，也 **必须不** 静默丢失待处理交互；当前呈现的交互弹层 **必须** 能指示所属 Tab/会话（推荐串行队列 + 角标，一次只弹一个）。串行队列调度 **必须** 满足：（1）**活动 Tab** 的 pending **优先**出队/呈现（可插队或双队列：活动优先、其余 FIFO）；（2）**当** 队头因超时 / fail-closed / Abort 结束 **时**，系统 **必须** 立即出队并尝试呈现下一项（无需用户再点）；（3）**当** 开发者切换到某 Tab 且该 Tab 存在 pending **时**，系统 **必须** 可主动唤起该项（仍保持串行、单弹层）。

**AC-21:** `[Must]` **状态驱动型** — **在** 多个 Tab 并行 running **期间**，各 Tab **必须** 可独立表现忙碌；对话面板 **必须** 仅展示**活动** Tab（或当前面板上下文）的运行状态，**必须不** 把非活动 Tab 的 busy 文案误标为活动面板唯一状态却无 Tab 区分。

**AC-22:** `[Should]` **普遍型** — Conversation Tab 标题 **应该** 使用会话标题（session/title 或等价）或首条用户消息的可读摘要，而非仅用不透明 id。

**AC-59:** `[Must]` **普遍型** — **在** 同一 VS Code 窗口内，同一会话 **必须** 同时只有一个可交互（live）视图上下文，且 **必须不** 为同一会话并存两条 OpenTab 记录（一条 replay + 一条 live）；「继续此会话」成功后 **必须** 在**同一 `tabId` 上原位**将 mode 从 replay 变为 live（默认 `sessionId` 不变；派生续写成功时 **可以** 同 `tabId` 换绑新 `sessionId`），**必须不** 另开第二个同会话 Tab；**必须不** 为同一会话并行打开第二个 live 视图。

### E. 关 Tab 可恢复、删除会话、running 确认（A1–A3）

**AC-23:** `[Must]` **事件驱动型** — **当** 开发者关闭某一对话 Tab **时**，系统 **必须** 卸除该 Tab 的 UI，并 **必须** 保留权威会话使之可从历史再次打开；**必须不** 将「关闭 Tab」默认等同于 dispose/清除权威会话。（**改变**前序 vscode-dsh-ide / README 默认关 Tab dispose 策略。）无实质消息的空 Tab 关闭见 AC-82。

**AC-24:** `[Must]` **事件驱动型** — **当** 开发者关闭活动 Tab **时**，对话面板 **必须** 停止展示该已关闭 Tab 的消息流，并切换到新的活动 Tab 投影或无 Tab 空态。

**AC-25:** `[Must]` **不期望行为型** — **如果** 开发者关闭 Tab 时该会话仍在 running，**那么** 系统 **必须** 弹出确认，选项至少包含「停止并关闭」与「取消」；确认文案 **必须** 标明「停止」**不可逆**（将损失进行中回合）；选择「取消」**必须不** 关闭 Tab；选择「停止并关闭」**必须** 停止该会话运行并执行卸 UI（权威仍按可恢复策略保留，除非用户另行删除）。

**AC-26:** `[Must]` **事件驱动型** — **当** 开发者对某会话执行显式「删除会话」且已通过任何必需确认 **时**，系统 **必须** dispose 并清除该权威会话，使其 **必须不** 再能从历史以正文回放方式打开；此路径 **必须** 与「关闭 Tab」可区分；该会话 **必须** 从未关 Tab 集合与历史可打开集合中移除。（回归：显式删除仍能彻底结束会话。）非 running 删除确认见 AC-81；running 删除确认见 AC-72。

**AC-60:** `[Must]` **事件驱动型** — **当** 开发者删除某会话且该会话存在已打开的 live 或回放视图 **时**，系统 **必须** 关闭对应 Tab（选定：关 Tab；**必须不** 保留「已删除」死态 Tab）。

**AC-61:** `[Must]` **事件驱动型** — **当** 开发者删除父会话 **时**，系统 **必须不** 自动级联删除子会话的权威会话日志；因父委托而钉成的子 Tab **必须** 关闭；子会话权威若仍独立存在，**必须** 仍可单独出现在历史中并可单独删除（除非 Spike 证明生命周期绑死父——见 T-4）。

**AC-62:** `[Must]` **普遍型** — 「删除会话」入口 **必须** 在历史列表行与回放视图顶栏均可被发现；**必须不** 仅依赖隐蔽菜单作为唯一入口。

**AC-72:** `[Must]` **不期望行为型** — **如果** 开发者删除某会话且该会话仍在 running，**那么** 系统 **必须** 弹出确认，选项至少包含「停止并删除」与「取消」；确认文案 **必须** 标明「停止」**不可逆**且将丢失进行中回合（与 AC-25 对齐）；选择「取消」**必须不** 删除会话；**在** 用户确认「停止并删除」**之前**，系统 **必须不** 对该会话执行 dispose / 清除权威。

**AC-73:** `[Must]` **不期望行为型** — **如果** Host 未连接或未就绪，**那么** 「删除会话」入口 **必须** 禁用，或明确标明「Host 连接后可删除」（或等价）；系统 **必须不** 仅从扩展索引移除该会话而保留权威会话日志，以致随后 Host 就绪后该会话再次出现在可回放历史中（删除假象）。

**AC-74:** `[Must]` **事件驱动型** — **当** 子会话已被删除且开发者仍查看父会话上下文 **时**，父流中对应 subagent 卡片 **必须** 显示「子会话已删除」（或等价），且 **必须不** 允许进入该子会话；父会话其余消息与状态 **必须** 不受影响。

**AC-75:** `[Must]` **事件驱动型** — **当** 父会话已被删除且开发者仍打开独立子会话视图 **时**，面包屑（或等价返回入口）**必须** 显示「父会话已删除」（或等价）并禁用返回父会话；子会话其余可回放内容 **必须** 仍可阅读。

**AC-27:** `[Could]` **可选功能型** — **若** 产品后续启用「关 Tab 时后台跑完再变历史」，该行为 **必须** 有独立确认或显式设置，且 **必须不** 静默替代 AC-25 的默认「停止并关闭」；本 feature 默认 **不** 将此列为 Must（S-20 保持 Out）。

**AC-81:** `[Must]` **不期望行为型** — **如果** 开发者删除某会话且该会话**不在** running，**那么** 系统 **必须** 弹出简单确认（不必要求输入标题），选项至少包含确认删除与「取消」；选择「取消」**必须不** 删除会话；**在** 用户确认删除 **之前**，系统 **必须不** 对该会话执行 dispose / 清除权威（与 AC-72 running 删除确认区分：本条无「停止」语义）。

**AC-82:** `[Must]` **事件驱动型** — **当** 开发者关闭某一对话 Tab 且该 Tab **无实质消息**（空会话 / 尚未产生可入历史的用户或助手正文）**时**，系统 **必须** 仅卸除该 Tab UI 并从「未关 Tab 集合」移除；**必须不** 将该空会话写入历史可打开集合；**必须不** 对其 dispose；**必须不** 无故弹出确认（running 空 Tab 仍遵循 AC-25）。

### F. 历史列表、只读回放、继续此会话、重启恢复（B + P1-A）

**AC-28:** `[Must]` **普遍型** — 系统 **必须** 提供仅覆盖**当前工作区**的会话历史列表；列表项 **必须** 至少展示标题与修改时间（mtime）；续写能力元数据 `continueCapability` 的**列表展示映射必须**为：`same-id` → 可显示「可继续」（或等价）；`derive-only` → 可显示「可继续（将开新会话）」（或等价）；`unknown` / 未探测 → **必须不** 显示任何「可继续」暗示；T-0b FAIL / 能力不可用 → **必须不** 显示「可继续」暗示；**必须不** 使用含糊的「只读/可继续」二元标记；打开任一历史项后 **必须** 一律先进入回放视图；「继续此会话」顶栏是否可用由 **T-0b** + 能力探测决定（可与列表暗示独立）；**应该** 支持可选首句摘要字段（有则显示，无则不编造）。

**AC-29:** `[Must]` **不期望行为型** — **如果** 某会话不属于当前工作区，**那么** 它 **必须不** 出现在该工作区的历史列表中。

**AC-63:** `[Must]` **普遍型** — 历史列表 **必须** 可基于扩展索引独立于 Host 连接状态展示；**必须不** 因 Host 未连接而整表空白且无说明。

**AC-30:** `[Must]` **事件驱动型** — **当** 开发者从历史打开某一会话 **时**，系统 **必须** 以**回放视图**呈现：从权威会话日志重建对话面板消息流与 Timeline 调试投影；**必须** 创建或激活对应 Conversation Tab（本版无临时 peek）；该 Tab **必须** 计入未关 Tab 集合；输入区 **必须** 禁用；UI **必须** 明确标识「回放中」（或等价文案）。

**AC-64:** `[Must]` **事件驱动型** — **当** 开发者从历史打开某一会话且该会话**已有 live Tab** **时**，系统 **必须** 激活现有 live Tab，**必须不** 新建只读回放副本。

**AC-65:** `[Must]` **事件驱动型** — **当** 开发者从历史再次打开某一会话且窗口内**仅有该会话的回放 Tab**（无 live）**时**，系统 **必须** 激活已有回放 Tab，**必须不** 再叠第二个回放 Tab。

**AC-31:** `[Must]` **不期望行为型** — **如果** 面板处于只读回放模式，**那么** 系统 **必须不** 对该回放会话发出 `session/prompt`（或等价发送）；发送动作 **必须** 不可用或被拒绝并有可感知反馈（需求 **必须不** 绑定具体协议消息名）。

**AC-76:** `[Must]` **不期望行为型** — **如果** 回放视图中某一 Timeline Diff 入口所对应的可恢复补丁/快照**不存在于**权威会话日志，**那么** 该 Diff 入口 **必须** 禁用，并说明「历史会话未保留该 Diff 快照」（或等价）；系统 **必须不** 以当前工作区内容冒充该历史 Diff。**当** 权威会话日志含可恢复补丁/快照 **时**，回放视图中的 Timeline Diff **必须** 可用。

**AC-77:** `[Must]` **普遍型** — 回放视图 **必须** 仅展示权威会话日志中已完整提交的事件；因停止/中断导致的未完成回合 **必须** 标「该回合已停止/未完成」（或等价）；系统 **必须不** 将不完整输出按完整助手消息呈现。

**AC-32:** `[Should]` **事件驱动型** — **当** 开发者在回放视图顶栏（或等价位置）选择「继续此会话」且该动作**成功** **时**，系统 **必须** 在**同一 `tabId` 上原位**将该上下文转为可发送 prompt 的 **live** 模式（更新 OpenTab `mode: replay → live`），解除回放禁用，并清除「回放中」标识（或改为 live 标识）；**必须不** 另建同会话第二 Tab；产品意图 **优先** 在同一 `sessionId` 的权威会话日志上续写（不 fork）；**仅在** Continue 成功后才将 mode 改为 live（失败 **必须不** 误改 mode）。

**AC-66:** `[Must]` **不期望行为型** — **如果** 执行「继续此会话」（同 id 续写或被迫派生），**那么** 系统 **必须不** 改写/篡改已落盘的旧权威会话日志前缀。

**AC-67:** `[Must]` **事件驱动型** — **当** 「继续此会话」因 DSH 能力限制只能派生新 session **时**，UI **必须** 标明「新会话 · 接续自 &lt;原标题或 id&gt;」（或等价可读文案）；扩展索引 **可以** 关联新旧会话；系统 **必须** 优先在**同一 `tabId`** 上换绑新 `sessionId`（仍单 Tab），**必须不** 让用户误以为旧会话被原地续写。

**AC-68:** `[Must]` **普遍型** — 「继续此会话」的后端可行性（同 id 续写 vs 派生）**必须** 在实施前通过 **Spike Gate T-0b**（见开放问题）；该 Gate **必须** 阻塞包含「继续此会话」交付的 Phase；**必须不** 阻塞纯只读回放 Phase（纯只读回放由 T-0a 约束，不受 T-0b 阻塞）。

**AC-80:** `[Must]` **普遍型** — 含「历史回放重建消息流 + Timeline turn/tool」的交付 **必须** 在实施前通过 **Spike Gate T-0a**（验证权威会话日志内容足以支撑 AC-30 / AC-47）；该 Gate **必须** 阻塞此类 Phase；**必须不** 阻塞纯 live 面板 Phase（不依赖历史回放重建）。

**AC-33:** `[Must]` **事件驱动型** — **当** 开发者重启扩展宿主或重新打开已保存「未关 Tab 集合」的窗口/工作区会话 **时**，系统 **必须** 自动恢复上次未关闭的 Tab 集合；各恢复的 Tab **必须** 先处于只读回放；**必须不** 在无「继续此会话」动作的情况下自动对恢复 Tab 发送 prompt。

**AC-69:** `[Must]` **状态驱动型** — **在** 打开历史或执行重启 Tab 集恢复且 Host 尚未连接/就绪 **期间**，系统 **必须** 显示「等待 Host 连接/启动」（或等价）可见态，**必须不** 以空白误导为「无内容/已损坏」；**当** Host 连接就绪 **时**，系统 **必须** 自动将该等待上下文重建为只读回放视图。

**AC-70:** `[Must]` **不期望行为型** — **如果** UI 对重启恢复施加「最近 N 个」上限或懒加载，**那么**：扩展索引 **必须** 仍保留全部未关 Tab 身份；构建恢复 UI 集 **时** **必须** 先将**上次活动 Tab** 恒纳入（优先于 mtime 截断），再按最近性补足至至多 N 个（即活动优先 + 最近 N−1）；UI **必须** 提供「查看更多 / 全部恢复」（或等价）入口以恢复超出部分；未进入 UI 的 Tab **必须不** 等同于从扩展索引丢弃；上限/懒加载行为 **必须** 文档化；系统 **必须不** 在无提示的情况下静默丢弃用户未关 Tab 身份。

**AC-34:** `[Must]` **事件驱动型** — **当** AC-33 的 Tab 集恢复完成 **时**，系统 **必须** 自动聚焦上次活动 Tab；因 AC-70 恢复 UI 集规则，上次活动 Tab **必须** 已在恢复 UI 集中（若其身份仍存在于扩展索引未关 Tab 集合）；若上次活动 Tab 身份已不存在于索引，则聚焦恢复集中的一个文档化默认 Tab 或空态，且行为可预测。

### G. Subagent 可进入（D1–D4）

**AC-35:** `[Must]` **事件驱动型** — **当** 开发者在父会话消息流中的 subagent 卡片（或等价入口）上选择进入 **时**，系统 **必须** 将对话面板切换为该子会话视图（可读消息流），**必须不** 仅显示不可进入的静态标记。（若子会话已删除，见 AC-74。）

**AC-36:** `[Must]` **普遍型** — 子会话视图 **必须** 提供面包屑或等价导航以返回父会话面板上下文。（若父会话已删除，见 AC-75。）

**AC-37:** `[Must]` **普遍型** — 进入子会话 **必须** 默认为面板上下文切换；子会话 **必须不** 默认自动占用一条 Conversations Tab。

**AC-38:** `[Should]` **事件驱动型** — **当** 开发者选择将子会话「钉成 Tab」**时**，系统 **应该** 为其创建 Conversations Tab，并与普通 Tab 一样可切换。

**AC-78:** `[Must]` **事件驱动型** — **当** 子会话**已钉成 Tab** 且开发者从父会话卡片进入该子会话 **时**，系统 **必须** 激活已有子 Tab，**必须不** 在父 Tab 内再切换为该子会话上下文。

**AC-79:** `[Must]` **事件驱动型** — **当** 开发者选择「钉成 Tab」且当前面板上下文正处于该子会话 **时**，系统 **必须** 将该子会话上下文提升为独立 Tab，并将父 Tab 恢复到父会话视图（与 AC-59 同会话单 live 一致）。

**AC-39:** `[Must]` **状态驱动型** — **在** 子会话进行中且父面板仍为当前上下文 **期间**，父面板 **必须** 显示「子代理运行中」（或等价）可见状态；**当** 该子会话结束且父面板仍为当前上下文 **时**，系统 **必须** 清除该「子代理运行中」标记（卡片可改为「已结束，可进入回放」或等价）。

**AC-40:** `[Must]` **事件驱动型** — **当** 子会话结束后 **时**，开发者 **必须** 仍能从父流入口进入该子会话的只读回放；子会话的回放 vs 继续策略 **必须** 与父会话的 P1-A 规则一致（打开默认只读；继续为 Should）。

**AC-71:** `[Must]` **状态驱动型** — **在** 子会话仍在运行中且开发者已进入该子会话视图 **期间**，系统 **必须** 以**只读实时投影**呈现（**必须不** 在未点「继续」时允许对该子会话发送 prompt）；**当** 该子会话结束 **时**，系统 **必须** 自动将该视图转为只读回放视图，**必须不** 要求用户重新进入。

**AC-83:** `[Should]` **普遍型** — 扩展索引中的「已删除」本地墓碑（用于父/子已删导航文案）**应该** 在仍被打开视图或其他索引条目引用期间保留；**如果** 某墓碑已无引用且超过文档化时间窗口（例如 30 天），**那么** 系统 **可以** 清除该墓碑；清除 **必须不** 影响仍可回放的权威会话正文，也 **必须不** 使仍打开的父/子导航误指向幽灵入口而无说明。

### H. 等待交互可见性（不重做审批 UI）

**AC-41:** `[Must]` **状态驱动型** — **在** 当前面板上下文会话存在未结算的 Host bridge 审批或提问 **期间**，对话面板 **必须** 展示明确的「等待交互」可见状态。

**AC-42:** `[Must]` **普遍型** — 审批/提问的选项呈现与合法结局回传 **必须** 继续经由既有 Host bridge + `InteractionUi`（默认 QuickPick/InputBox）完成；本 feature **必须不** 将「用 Webview 重做完整审批/提问表单」列为 Must 交付。

**AC-43:** `[Must]` **不期望行为型** — **如果** 审批/提问 fail-closed、超时、Abort 或宿主断开，**那么** 对话面板的「等待交互」状态 **必须** 解除或转为错误/空闲可见态；**必须不** 无限期卡在等待态且无说明。

**AC-44:** `[Could]` **可选功能型** — **若** 提供「打开审批/提问」面板动作，该动作 **必须** 仅唤起既有 `InteractionUi`，**必须不** 引入第二套结局映射权威源。

### I. 权威边界（F1–F3）

**AC-45:** `[Must]` **普遍型** — 消息正文与可回放历史的**权威源** **必须** 是权威会话日志（DSH session log 或其既有持久化权威）；扩展 **必须** 仅做投影与扩展索引，**必须不** 将扩展本地存储当作聊天正文权威库。

**AC-46:** `[Must]` **普遍型** — 扩展本地持久化 **必须** 最多用于：未关 Tab 集合、活动 Tab、工作区级扩展索引、UI 偏好、继续派生时的新旧关联等非正文元数据；**必须不** 用本地副本覆盖或静默改写权威会话日志中的助手/用户正文。

**AC-47:** `[Must]` **普遍型** — 只读回放视图 **必须** 能够从权威会话日志重建对话面板消息流与 Timeline 调试投影；重建后，消息的**条数、顺序、角色/作者文本**与 Timeline 的 **turn/tool 条目** **必须** 可与权威会话日志**逐项比对一致**；验收 **必须不** 把某一具体 RPC 方法名写死为本需求的唯一合法实现（RPC 选型属设计阶段）。

### J. 与既有窗口壳共存 / 依赖边界

**AC-48:** `[Must]` **普遍型** — 实现 **必须不** 修改 `packages/core/agent-loop`（含其源码与为绕过本约束而改循环语义的同义路径）。

**AC-49:** `[Must]` **普遍型** — 新行为 **必须** 优先落在 `apps/vscode-dsh`；若需 bridge 侧薄适配，**必须** 落在 `packages/ide/ide-bridge` 既有拥有面内，并保持 stdout 专属 SDK、bridge 非 stdout、fail-closed 不变量。

**AC-50:** `[Must]` **普遍型** — 引入对话面板与可恢复关 Tab 策略后，下列既有能力 **必须** 仍可验证可用：Conversation Tab 栏、Timeline TreeView（弱化后仍含 turn/step/tool/Diff）、事后 Diff、`permission-presets`、审批/提问 fail-closed、AD-8 `setInteractionUi` 替换面。

### K. 安全、失败与验证

**AC-52:** `[Must]` **普遍型** — 系统 **必须不** 将 API Key / Token 等密钥明文写入面板 HTML、扩展日志、spec 或提交物（Constitution §3.2）。

**AC-54:** `[Must]` **状态驱动型** — **在** 每个**产品**交付 Phase（非纯 Spike）的验证中，**必须** 至少包含 1 个真实组件集成测试（可属 **L1**）与 1 个独立 e2e 场景；该独立 e2e **必须** 在扩展测试宿主（**L2**，优先 `@vscode/test-electron` 或设计选定的等价 Extension Host runner）上可脚本执行，并覆盖至少一条下列路径之一：「面板发送 → 投影出现用户/助手消息」「切 Tab → 面板内容切换」「关 Tab → 历史可回放打开」「删除会话 → 不可再回放正文」。**在** 本 feature 整体交付结束前，路径清单 **必须** 另包含并至少各独立覆盖一次：「重启恢复 Tab 集」「进入子会话（运行中或回放）」——可跨 Phase，但 **必须不** 缺席（Constitution §1.2–§1.3）。**仅** L1 Node 库测或 **仅** 人工点选（**L4**）**必须不** 作为该产品 Phase 达标的唯一证据。

**AC-84:** `[Must]` **普遍型** — 产品 Phase（非纯 Spike）的 verifier **PASS** **必须** 以可脚本执行的 **L2** 扩展宿主自动证据为硬前提（命令、退出码、关键日志落盘于 `test-scripts/` 与 `verification.md`）；对话面板相关 Phase 的 **PASS** **必须** 另含本 Phase 适用的 **L3** Webview 消息契约自动证据。**必须不** 以 **仅** L1 或 **仅** L4 作为 PASS 依据。纯 Spike Phase（T-0a / T-0b / phase-0a / phase-0b）除外，但仍 **必须** 留下 Gate 报告与可复核证据。

**T-2（技术）：** 工作区扩展索引与「上次未关 Tab 集」落在 VS Code workspaceState / 扩展存储 / 其他索引面的具体形态，以及 UI 恢复「最近 N」（**上次活动 Tab 恒优先 + 最近 N−1**）与「查看更多 / 全部恢复」阈值——属设计选型，验收以 AC-28/33/34/46/63/70 为准；索引层**必须**保留全部未关 Tab 身份。

**T-3（技术）：** 子会话「钉成 Tab」（Should）与父 Tab 生命周期的细节——属设计选型；产品已锁定：父删关闭钉成子 Tab、不级联删子权威；已钉后从父进入激活已有子 Tab；钉定时提升并恢复父（AC-78/79）。验收以 AC-35–38 / AC-61 / AC-71 / AC-74/75 / AC-78/79 为准。

**T-4（技术 · 父删子生命周期）：** 若 Spike/实现发现子会话权威生命周期绑死父（无法独立保留），须在设计中显式记录例外与用户可见后果，并更新 tech-debt / 偏差；默认假设子权威可独立存在（AC-61）。

## 建议的 Phase 拆分方向

> 正式 DAG 由 plan-generator 产出；此处仅为高层指引，**不是** Phase 清单。按风险切分四段：

1. **面板 + 单会话历史只读 + 可恢复关 Tab / 删除**（含幽灵 Tab 关闭、Host 等待、历史独立于 Host、删除入口可发现、同会话激活已有 Tab、running 删除确认、Host 离线删除、子/父已删导航；含回放重建前须过 **T-0a**）。
2. **多 Tab 未读 / 审批角标 / 并行 busy 呈现 + 交互串行绑定**（防错配；Timeline 短 label；可选点击定位）。
3. **重启恢复未关 Tab 集（只读 + 索引全保留 + UI 限 N/查看更多）+「继续此会话」（须先过 T-0b Spike Gate）**。
4. **Subagent 进入：先读/回放（含运行中只读实时投影 → 自动回放），后继续/钉 Tab（含 AC-78/79）**。

**不**将 Spec 面板、hooks 包、GAP-010/011、审批表单重做、跨工作区历史、S-20 列入本 feature Phase Must。
